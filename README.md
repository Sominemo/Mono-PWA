# monobank PWA
monobank Progressive Web Application  
Неофіційний клієнт monobank - [Відкрити](https://monoweb.app)

## Список можливостей - [Лендінг](https://sominemo.com/mono)
### Робота з профілями
- Додавання декількох профілів monobank
- Необмежена кількість прив'язуваних пристроїв - [Список пристроїв](https://api.monobank.ua)
- Авторизація за приватним токеном - [Отримати токен](https://api.monobank.ua)
- Спрощена авторизація через корпоративний сервер (встановлено за замовчуванням)
- Зміна корпоративного сервера на власний:  
  Для роботи застосунку з корпоративним API підтримується сервер mono Corp API Proxy. За замовчуванням використовується власний сервер [[адреса]](https://api.mono.sominemo.com) - [Реалізація](https://github.com/Sominemo/mono-Corp-API-Proxy-PHP)

### Курси валют**
- Список курсу валют від monobank
- Вбудований конвертер валют (за натисканням на курс)
- Доступ до курсу валют в автономному режимі

### Виписка (Історія операцій)*
- Список операцій
- Збереження та доступ до історії в автономному режимі
- Категоризація операцій
- Список рахунків з усіх підключених акаунтів
- Показ/відключення копійок
- Завантаження виписки наперед

### Рахунки*
- Автоматичне визначення типу карти
- Зміна порядку карт
- Зміна зовнішнього вигляду карт

### Сповіщення*
- Налаштування Push-сервера
- Отримання сповіщень від сервера
- Сповіщення про транзакції

### Додатково
- Управління сховищем
- Автономний режим

## Мови
- Українська (Основна)
- Російська
- Англійська
